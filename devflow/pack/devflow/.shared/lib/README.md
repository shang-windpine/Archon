# devflow shared library

Import from a workflow script as `../../.shared/lib/<module>.ts` (from `<workflow>/scripts/x.ts`) or `../lib/<module>.ts` (from `.shared/scripts/x.ts`). **Pure** modules import nothing from `archon:script` at runtime (type-only imports are erased) and are unit-tested in `devflow/test/lib/` without a preload. **Host** modules call `forge()` and only run inside a script node (or with the `archon script preload`).

Every function that touches git runs in `process.cwd()` unless it takes a `checkout` argument. Errors are thrown as `Error` with an operator-readable message; a script catches at its top level and calls `refuse()`.

| Module | Kind | Contract |
|---|---|---|
| `inputs.ts` | pure | `nullableJson(bound: string \| undefined): unknown` — a `with:` binding as JSON; `''` and `null` read as `null`, malformed JSON throws. `isObject(value: unknown): value is Record<string, unknown>`. `record(value: unknown): Record<string, unknown> \| undefined`. |
| `identity.ts` | pure | Types `PrRecord` (the forge's `pr.view` `.pr`), `Repo` (`{host, path}`), `QualifiedPr` (`{repo, number}`). `sameRepo(left: Repo, right: Repo): boolean` and `samePr(left: QualifiedPr, right: QualifiedPr): boolean` compare case-insensitively. `parseQualifiedPr(bound: string \| undefined): QualifiedPr` parses a bound PrRecord / `{repo, number}`, throws on anything else. |
| `git.ts` | pure (spawns git) | `git(...args: string[]): GitResult` (`{code, stdout, stderr}`, trimmed, never throws). `gitOrThrow(...args: string[]): string` — stdout, or throws naming the command. |
| `remote.ts` | pure (spawns git) | Remotes chosen by URL, never by name. `urlRepo(url: string): Repo \| undefined`. `remotes(checkout?): Remote[]` (`{name, url, repo}`). `remoteRepos(checkout?): Repo[]`. `checkoutRemote(checkout?): Remote` — the only remote, or `origin` among several; throws otherwise. `findRemote(repo: Repo, checkout?): string \| undefined` (throws when several remotes name it). `remoteFor(repo: Repo, checkout?): string` (throws on none). `fetchBranch(repo: Repo, branch: string, checkout?): string` — fetches `refs/heads/<branch>` into a throwaway ref and returns its commit SHA (use with `git merge-tree --write-tree <sha> HEAD` for the conflict check). |
| `push.ts` | pure (spawns git) | `pushHead(target: PushTarget, retryDelayMs = 20_000): string` with `PushTarget = {repo: Repo, head: string}` — `git push <remote-for-repo> HEAD:refs/heads/<head>`, never forced, one retry after `retryDelayMs`, then `ls-remote` read-back must equal HEAD; returns the pushed SHA or throws (a moved remote branch refuses). |
| `pr.ts` | host | `checkoutRepo(checkout?): Repo` — forge `resolve` of `checkoutRemote()`; throws when no plugin resolves it. `findOpenPrByHead(repo: Repo, head: string): PrView \| undefined` (`PrView = {pr: PrRecord, title, body}`; open PRs only, head in `repo` itself). `viewPr(ref: QualifiedPr): PrView` (throws when absent). `createPr(intent: CreatePrIntent): PrRecord` with `CreatePrIntent = {repo, head, headRevision, base, title, bodyPath}` — always `draft: true`; body read from `bodyPath`; on an unknown write outcome reads back the open PR on `head` and returns it, else rethrows; a forge refusal is rethrown. `setPrDraft(ref: QualifiedPr): PrRecord` — puts the PR back into draft (no-op when already draft), same read-back on unknown outcome. There is deliberately no ready operation. |
| `forge-check.ts` | host | `DEVFLOW_FORGE_OPERATIONS` — the ops devflow uses (`resolve, pr.view, pr.create, pr.draft, pr.threads, pr.thread.reply, pr.thread.resolve, pr.reviews, pr.files, checks.state, checks.logs, checks.rerun`). `requireForge(host: string, operations?: readonly string[]): ForgeOperations['check']['result']` — `archon forge check`, setup remedies appended to the error. `checkForgeAccess(checkout?): ForgeAccess` = `{repo, host, plugin: {name, version}, operations, credentialSource: string \| null, readVerified: true}` — check + resolve + one authenticated `pr.view`; write access is not proven. The named script `script: forge-check` (`.shared/scripts/forge-check.ts`) emits exactly this object or refuses. |
| `devflow.ts` | pure | `KEY_PATTERN`; `validateKey(key: string): string` (throws; no trimming). `stateDir(key: string): string` = `$STATE_DIR/devflow/<key>` (mkdir -p; validates key; throws when `$STATE_DIR` is unset/relative). `statePath(key: string, ...segments: string[]): string` (parent created). `runArtifactsDir(): string` = `$ARTIFACTS_DIR` (mkdir -p). `artifactPath(...segments: string[]): string` (parent created). `parseList(raw: string): string[]` (comma split, trimmed, empties dropped). `parsePositiveInt(raw: string, fallback: number, label = 'value'): number` (empty → fallback, junk throws). `parseEnum<T extends string>(raw: string, allowed: readonly T[], fallback: T, label = 'value'): T` (empty → fallback, other throws). `shellQuote(value: string): string`. `renderCommand(template: string, vars: Readonly<Record<string, string>>): string` — replaces `{name}` (identifier, not preceded by `$`) with a single-quoted shell word; unknown token throws; `${VAR}` and `{print $1}` pass through; do not put a token inside quotes in the template. `runCommand(command: string, options: RunCommandOptions): Promise<RunCommandResult>` with `RunCommandOptions = {cwd, timeoutMs, logPath, tailChars?: number (default 4000)}` and `RunCommandResult = {code: number \| null, timedOut: boolean, outputTail: string}` — `sh -c` in its own process group, combined stdout+stderr overwritten into `logPath`, the whole group SIGKILLed on timeout (`code` null), never throws for a failing command. Give the script node a `timeout:` larger than `timeoutMs`. |
| `copilot.ts` | pure | Types `ReviewItem` (a `pr.reviews` item), `ForgeAuthor`. `normalizeLogins(list: readonly string[]): ReadonlySet<string>` (trim, lowercase, drop empties) — feed it `parseList(input('copilot_logins'))`. `isCopilotAuthor(author: ForgeAuthor, logins: ReadonlySet<string>): boolean` — exact case-insensitive login match, no `[bot]` inference; author type `bot`/`user`/absent accepted, `organization` refused. `copilotReviewForHead(items: readonly ReviewItem[], headRevision: string, logins: ReadonlySet<string>): ReviewItem \| undefined` — latest (by `createdAt`, else forge order) `kind: 'review'` item by Copilot whose `commit === headRevision`; dismissed reviews count. |
| `checks.ts` | pure | Types `ChecksState` (the `checks.state` result), `CheckUnit`, `ChecksVerdict`. `summarizeChecks(checks: ChecksState, headRevision: string, requiredChecks: readonly string[]): ChecksSummary` with `ChecksSummary = {state: 'green'\|'red'\|'pending'\|'none'\|'gated'\|'unknown', stale: boolean, redUnits: readonly CheckUnit[], missingRequired: readonly string[], settled: boolean, green: boolean}`. `state` is the forge summary except: green with a missing required name → `pending`; `none` with `approvalPending === true` → `gated`. `stale` = `revision !== headRevision`. `settled` = not stale, state not `none`/`pending`, and no unit pending (so red+pending is not settled). `green` = state green and not stale — the only acceptance. `redUnits` are the forge's unit objects unchanged (pass them to `checks.rerun` as `{unit, rerun}`). |
| `deliver-outcome.ts` | pure | Types `AwaitCopilot` (`done\|timeout\|off\|request_failed`), `AwaitChecks` (`green\|red\|pending_timeout\|none\|gated\|unknown`), `ThreadDecision` (`{thread, decision: accept\|decline\|not_this_change\|needs_human, reason, reply}`), `CiJudgement` (`{name, cause: pr_caused\|infra\|flaky\|unknown, evidence, fix}`), `RerunRecord` (`{head, unit, at}`; store an array in `$ARTIFACTS_DIR/reruns.json`). `unitKey(unit: CheckUnit['unit']): string` = `<kind>:<name>`. `planReruns(redUnits: readonly CheckUnit[], judgements: readonly CiJudgement[], history: readonly RerunRecord[], head: string): RerunPlan` = `{rerun, repeated, notRerunnable, unjudged}` (each `readonly CheckUnit[]`; judgement matched by exact unit name; only infra/flaky with non-null `rerun` not yet rerun on this head go to `rerun`). `recordReruns(history, head, issued: readonly CheckUnit[], at: string): RerunRecord[]` (new array). `computeRoundOutcome(facts: RoundFacts): RoundOutcome` with `RoundFacts = {head, checks: AwaitChecks, summary: ChecksSummary \| null, copilot: AwaitCopilot, openThreads (unresolved after this round's replies), decisions, ciJudgement, conflict, rerunsIssued, rerunHistory (before this round)}` and `RoundOutcome = {done, has_work, ask, reasons: readonly string[]}` — DESIGN §6 rules, plus: unjudged red, rerun-not-issued, not-rerunnable infra/flaky, `checks: none`, a missing snapshot, and any not-done round with no work and no rerun all set `ask`. Call it with the history read *before* recording this round's reruns. |
| `deliver-settings.ts` | pure | `parseDeliverSettings(raw)` / `parseAwaitSettings(raw)` — validate the deliver pack settings (`copilot_mode`, waits capped at `MAX_WAIT_MIN`, lists); throw on junk. Callers read each setting with a literal `input('<name>')`. |
| `deliver-await.ts` | pure | `copilotVerdict`, `checksVerdict`, `pendingReruns` (a rerun counts as started only once the unit id changes), `unresolvedThreads` (snapshot shape), `logFileName`. |
| `deliver-work.ts` | pure | `fence` (untrusted text), `controlDecision`, `renderWorkOrder`, `hasNextWork` / `renderNextWork`, `reconcileDecisions` (unjudged or reply-less declines become needs_human), `fixedReplies` (`Fixed in <sha>: <note>`). |
| `delivery.ts` | pure | `DeliveryRecord` — the owner of the `delivery.json` shape (`pr.repo` is `{host, path}`); `deliveryRecord(facts)` builds it in deliver's finish. `verify.ts` `parseDelivery` reads it; `test/lib/delivery.test.ts` pins the round trip. |
| `refine.ts` | pure | `gateAsks` / `gateRecommendation` (refine_human × verdict × needs_human), `controlStep` (previous gate answer → finalize or next round), log entries (`runHeading`, `humanEntry`, `reviewEntry`, `fenced`, `numbered`), `finalizationLines`. |
| `verify.ts` | pure (spawns git) | `validateCases` (structured plan cases), `parseDelivery`, `locateChange` (kept worktree, then branch commit, then current checkout), `remoteDefaultBranch`, `resolveBaseRef`, `gitChangedFiles` / `parseNameStatusZ`, `renderResultsTemplate`, `planHeadline`. |
| `smoke.ts` | pure | `parseVersion` / `compareVersions` / `formatVersion`, `helpOffersCopilotReviewer`, `redactUrl`, `buildSummary` (node outcomes → `{ok, failures, warnings}`), `renderTable`. |
